# Cross-vendor handoff

Use a short repository file when work will move between Codex and Claude.

```markdown
# Handoff

## Goal
<end state>

## Current state
<what works, what does not, branch/worktree>

## Settled decisions
- <decision and reason>

## Next action
<one concrete next move>

## Verification
- `<command>` — <result>

## Risks and unknowns
- <unresolved item>
```

The outgoing collaborator updates it after material work. The incoming collaborator verifies it against the repository before proceeding. It is a state transfer, not a diary.
