# Local Codex routing policy

This is a user preference snapshot. Confirm the destination host's advertised models and supported effort levels before dispatch.

## Model preference

- **Sol:** consequential architecture, ambiguous diagnosis, difficult implementation, or adversarial review where judgment dominates cost.
- **Terra:** routine implementation, repository mapping, bounded debugging, and average work with clear acceptance criteria.
- **Luna:** mechanical, cheap, highly checkable edits, migrations, inventories, formatting, and repetitive tests.

If Luna needs high effort, prefer Terra. If Terra needs xhigh because judgment—not search volume—is hard, prefer Sol.

## Effort preference

- `low`: obvious, narrow, readily checked.
- `medium`: normal non-trivial work with a clear route.
- `high`: interacting constraints, obscure behavior, difficult diagnosis.
- `xhigh`: competing hypotheses, unfamiliar systems, consequential architecture.
- `max`: hardest quality-first work where uncertainty justifies the cost.

Use `ultra` only when the destination host explicitly supports it and there is a deliberate reason. Report unsupported combinations rather than silently changing both axes.
